# Vienna POI Explorer branding assets

These assets were cropped from the supplied generated branding sheet.

## Contents
- `assets/branding/`: app icon, header banner, promotional card and City of Vienna/Open Data badge.
- `assets/icons/`: individual navigation and action symbols, plus the combined icon strip.
- `assets/markers/`: individual POI category markers, plus the combined marker strip.
- `assets/ui/`: information button and status-indicator strip.
- `original-branding-sheet.png`: original reference image.

## Notes
- Files are PNG crops from a raster source, not editable SVG vectors.
- Some crops retain a small amount of surrounding whitespace or background from the source sheet.
- For production iOS use, create an AppIcon asset set with the appropriate platform sizes.
- Check trademark and attribution requirements before using official City of Vienna branding.
